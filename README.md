# Documentación de prueba practica   
- la prueba teorica se encuentra en el archivo **PRUEBA TEORICA ALAN JESUS CACERES MEDRANO.docx** que se encuentra en la raiz del proyecto  
- la prueba practica es todo el repositorio y se añadio capturas de las pantallas implementas. Solo se tiene una captura: **screen_1.jpg** que se encuentra en la raiz del proyecto.   

El proyecto esta totalmente hecho en kotlin y jetpack compose ya que asi lo pedia la vacante.  
el proyecto tiene librerias como hilt, retrofit, entre otros que no fueron utilizados para la prueba ya que al no saber que tipo de prueba harían se instalo estas librerias como prevención ante cualquier escenario.
